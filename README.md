# 🍫 Marshmallow Projects - Internship Portal

An interactive, and professional landing page for freshers to explore and select their internship fields at Marshmallow Projects.

## ✨ Features

### 🎨 Design & UX
- **Modern & Professional Design**: Clean, gradient-rich interface with smooth animations
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Elements**: Hover effects, animations, and transitions throughout
- **Accessibility**: Keyboard navigation, screen reader support, and ARIA labels
- **Dark Mode Ready**: Extensible color scheme system

### 🚀 Interactive Components
- **Navigation Bar**: Sticky navbar with smooth scrolling and active link indicators
- **Hero Section**: Eye-catching landing section with animated floating shapes
- **Internship Cards**: 6 internship fields with detailed information and interactive cards
- **Modal Selection**: Pop-up dialog for detailed internship information
- **Statistics Section**: Animated counters showing company achievements
- **Contact Section**: Quick links for email and Discord community

### 🎯 Internship Fields Available
1. **Web Development** - Frontend & Backend technologies
2. **UI/UX & Graphic Design** - Design principles and tools
3. **Data Science** - Machine Learning and Analytics
4. **Digital Marketing** - SEO, Social Media, Analytics
